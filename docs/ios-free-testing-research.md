# بحث تجربة ZAK على iPhone بدون رسوم Apple Developer

## النتائج الرسمية

- Apple تسمح بإنشاء حساب مطور مجاني عبر Apple Account وقبول اتفاقية المطور.
- Apple تذكر أن تثبيت التطبيقات على الجهاز الشخصي ممكن عبر Xcode دون التسجيل في Apple Developer Program.
- Apple Developer Program المدفوع تكلفته السنوية 99 دولاراً أو ما يعادلها محلياً.
- الإعفاء من الرسوم متاح فقط لكيانات مؤهلة: منظمة غير ربحية معترف بها، مؤسسة تعليمية معتمدة، أو جهة حكومية؛ وليس للفرد أو النشاط الفردي.
- Expo يوضح أن تثبيت Development Build على iPhone حقيقي عبر EAS يحتاج حساب Apple Developer مدفوعاً للتوقيع.
- Expo يوضح أن الطريقة الوحيدة لتثبيت Development Build على iPhone حقيقي دون حساب Apple مدفوع هي البناء المحلي على macOS باستخدام Xcode، مع جهاز iPhone موصول وتفعيل Developer Mode.
- iOS Simulator لا يحتاج جهاز iPhone ولا حساب Apple مدفوع، لكنه يعمل على macOS فقط ولا يمثل تثبيتاً على الهاتف الحقيقي.
- TestFlight وتوزيع التطبيق للمستخدمين يتطلبان عضوية Apple Developer Program المدفوعة.
